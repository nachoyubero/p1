# Práctica 1: Programación de Aplicaciones Telemáticas
## Autor: Nacho Yubero - ICAI

### 1. Descripción
Esta práctica configura el entorno de desarrollo para la asignatura, incluyendo **Git**, **Java** y **Maven**.

### 2. Diario de Comandos Git
Aquí se específican los comandos ejecutados:
- `git clone`: Descargué el repositorio a mi carpeta local.
- `git status`: Comprobé el estado de los archivos antes de añadirlos.
- `git add`: Pasé los archivos al área de preparación (staging).
- `git commit`: Guardé la versión en mi historial local.
- `git checkout`: Se crea la rama "mejoras-readme" para editar el README sin tocar el main.
